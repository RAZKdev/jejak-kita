# Jejak Kita

A modern, accessible personal travel planner and memory journal web application designed for thoughtful family journeys, gentle pacing, transparent budget management, and preserving meaningful memories.

## Overview

**Jejak Kita** provides a calm, dignified planning experience focused on comfort, clear decision-making, and memorable travel storytelling. The platform helps travelers organize flexible itineraries, manage trip finances, and keep a lasting journal of their journeys without overwhelming complexity.

## Key Features

- **Pacing & Accessibility Management**: Plan daily schedules with dedicated rest intervals, low-stress transit options, and comfortable walking intensity indicators.
- **Interactive Itinerary Builder**: Organize multi-day travel timelines with categorization for sights, dining, accommodation, and rest breaks.
- **Budget & Expense Tracking**: Monitor planned ceilings against actual realization across travel categories with instant financial balance calculations.
- **Readiness Checklist**: Keep track of essential travel documents, health supplies, comfort items, and packing essentials with grouped progress indicators.
- **Personal Memory Journal**: Record heartwarming travel stories, reflective moments, and photo memories with accessible captions and favorite pins.
- **Transparent Recommendation Engine**: Evaluate destination compatibility against travel preferences, highlighting supporting factors and practical trade-offs.

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Validation**: Zod (domain schemas and API contracts)
- **Styling**: Tailwind CSS (accessible ergonomics, responsive design, custom design tokens)
- **Database & Storage**: Supabase / PostgreSQL (Row-Level Security enabled)
- **Testing**: Vitest & Testing Library

## Getting Started

### Prerequisites
- Node.js 18.17+ or later
- npm or yarn

### Installation

1. Clone repository:
   ```bash
   git clone https://github.com/RAZKdev/jejak-kita.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. Run automated tests:
   ```bash
   npm test
   ```

5. Build for production:
   ```bash
   npm run build
   ```
