# Jejak Kita — Perjalanan Rangga & Ibu

Private full-stack travel planner and memory journal for Rangga and his mother.

## Primary Destinations
- Japan (Tokyo, Kyoto, Osaka)
- South Korea (Seoul, Busan, Gyeongju)
- China (Beijing, Shanghai, Xi'an)

## Alternative Candidates
- Singapore
- Malaysia (Kuala Lumpur, Penang)
- Taiwan (Taipei, Tainan)
- Thailand (Bangkok)

## Core Philosophy
The product assists Rangga and his mother in transparently comparing travel options, planning itineraries with comfort-focused preferences, and preserving travel memories. Human decisions remain authoritative; the system never makes autonomous travel commitments or bookings.

## Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Supabase (PostgreSQL, Auth, Storage)
- Zod
- Vitest & Playwright
